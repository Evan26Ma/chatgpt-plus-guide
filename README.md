# ChatGPT Plus 开通互动向导

> 把复杂的准备流程，整理成一段清晰、轻松、可以一步步完成的互动旅程。

这是一个面向学习交流的静态互动页面。它通过分支式流程、图文卡片、进度保存和安全提醒，帮助使用者按照自己的情况了解 ChatGPT Plus 的准备与使用步骤。

## 你可以用它做什么

- 根据账户、网络环境和准备情况，自动进入适合自己的流程
- 通过清晰的步骤卡片和图文提示，减少来回查找资料的时间
- 自动保存浏览进度，刷新页面后可以继续上次的步骤
- 使用返回、重置、图片放大和常见问题等实用功能
- 在账户、支付、网络和信息安全相关步骤查看风险提醒

## 页面特点

### 清晰的流程

将准备过程拆分为多个阶段，用简单的问题引导使用者逐步完成，不需要一次记住全部内容。

### 轻量的交互

页面采用原生 HTML、CSS 和 JavaScript 构建，无需登录、数据库或后端服务，打开静态文件即可使用。

### 友好的阅读体验

采用卡片式布局、响应式设计、图片放大、键盘操作和减少动画支持，电脑与手机都可以阅读。

### 安全边界

页面只做信息整理和学习交流，不收集账号密码、验证码、支付信息、身份证件或人脸信息。使用第三方服务时，请自行核对官方页面、条款、价格和资格要求。

## 本地使用

直接打开 `index.html` 即可预览；如果浏览器限制本地脚本，也可以在当前目录运行：

```bash
python3 -m http.server 8080
```

然后使用浏览器访问本机的 `8080` 端口。

## 文件说明

```text
index.html   页面结构与访问前确认
styles.css   视觉样式、布局和响应式规则
app.js       流程内容、步骤分支和图文素材配置
ui.js        页面渲染、状态保存、弹窗和交互逻辑
*.png/*.jpg  教程图文素材
```
